# Decisions

## Settled

Each one names the alternative we rejected and the evidence. To change one, update this file first, then the code. When a later decision replaces one, the old text stays after "Was:" (D14). When a later decision amends one, the row is edited in place and ends with "Amended by D46: ...", or carries "(D46)" where only the wording changed.

| D34 | Monte Carlo draws every line of the background that has a distribution, once per iteration, factorizes A again and solves every indicator, so one iteration serves every product and study ([calculation](calculation.md#uncertainty)). ## Open

Each with an example and a recommendation.

### 1. Register the name on PyPI now?

Settled: published as `headwater` from 0.1.0. See D47.

### 2. What does overriding a background process mean by default?

Settled: local by default, global only in a named scenario. See D23.

### 3. When to open-source?

Settled: Apache-2.0, public on GitHub and on PyPI from 0.1.0. See D47.

### 4. What may be shared from licensed data?

- a. Check the ecoinvent licence terms for derived indicator tables (one score per product for every product) and presampled results, before setting up shared buckets.
- b. Assume the terms that cover publishing a few emission factors also cover this.

**Recommend a.** A table of solved scores for every dataset is much more than a few factors and may count differently.

### 5. Are named parameters first-class?

Settled: yes, first-class. See D24.

### 6. Which solver backends besides SciPy?

- a. Benchmark UMFPACK, PARDISO and others in M1, and add one only if it wins on the machines we target.
- b. Add several backends from the start.

**Recommend a.** With the right settings, SciPy's factorization already takes seconds; other backends were not tested.

### 7. How do people who do not use git edit, later?

- a. A service that opens branches and pull requests for them.
- b. DuckLake with a Postgres catalog as a shared editable store.

**Recommend deciding when a real user needs it.** Both fit the design; the right one depends on who that user is.

### 8. Should a SimaPro method's unspecified factors cover every subcompartment?

Settled: yes, as SimaPro and Brightway's SimaPro import do, and each copied factor is counted in the import report. Owner's choice, 25 October 2026. See [Methods and indicators](design.md#methods-and-indicators).
